A handful of things I've built outside of the day job — home-lab tooling, open source, and the occasional weekend rabbit hole.

## LunaTV — a mobile-first HDHomeRun client

[Full write-up]({% post_url 2026-08-26-hdhomerun-web %})

A self-hosted, mobile-first client for watching and browsing live TV from an [HDHomeRun](https://www.silicondust.com/) tuner. It includes a browser client and a sideloadable Roku app, QSV-accelerated H.264/HLS transcoding, and a much friendlier device-administration interface than the tuner's built-in web UI.

## ytpi — automated downloads for your home server

[Full write-up]({% post_url 2025-07-20-ytpi %}) · [Source code](https://github.com/joescars/ytpi)

A lightweight [Flask](https://flask.palletsprojects.com/) web app that automates downloading YouTube videos and playlists with `yt-dlp` onto a home server or Raspberry Pi — with a live progress dashboard, category-based organization, and LAN-only access.

## Azure Functions Data Lake extension

[Full write-up]({% post_url 2018-09-10-azure-data-lake-extension-for-azure-functions %}) · [Source code](https://github.com/Azure/azure-functions-datalake-extension)

An input/output binding extension that lets Azure Functions talk directly to Azure Data Lake Store — built during an internal Microsoft hack week and shipped to the official Azure repositories.
